# Cómo rellenar `escribir-como-yo`

Tiempo estimado: 45-60 minutos, una sola vez.

## 1. Reúne 10-15 textos tuyos (variados)
| Tipo | Cantidad | De dónde sacarlos |
|---|---|---|
| Mensajes a amigos (WhatsApp/Telegram) | 3 | conversaciones normales, mensajes de 3+ líneas |
| Correos formales (a profesores, oficina de intercambio) | 3 | bandeja de enviados |
| Textos largos personales (notas de Obsidian, reflexiones) | 3 | vault de Obsidian |
| Posts o textos "públicos" (LinkedIn, descripciones de GitHub) | 2-3 | perfil |
| Mensajes en inglés (si quieres estilo bilingüe) | 1-3 | |

**Reglas:** textos escritos **por ti sin IA**; quita nombres, teléfonos, DNI, direcciones; **no uses trabajos de la universidad**.

## 2. Pégalos en `referencia/ejemplos.md`
Con el formato que ya tiene el fichero (tipo, destinatario, texto, por qué es representativo).

## 3. Extrae tu estilo con Claude
Abre una conversación nueva con los ejemplos y este prompt:

```text
Analiza estos textos míos y extrae una guía de estilo con: longitud media de frase y párrafo,
tono por destinatario, saludos y despedidas típicos, expresiones recurrentes, cosas que nunca hago,
uso de emojis y puntuación, y estructura típica por tipo de texto. Cita ejemplos literales de cada
rasgo. Luego rellena esta plantilla: <pega referencia/guia-estilo.md>
```

Revisa el resultado: **borra todo lo que no reconozcas como tuyo**.

## 4. Prueba ciega
Pide 3 textos con la skill (un mensaje, un correo, un post), mézclalos con 3 tuyos reales y pregúntate si distinguirías cuáles son tuyos. Lo que delate a la IA → a la lista negra.

## 5. Mantenimiento
Cada vez que corrijas un borrador, añade la regla aprendida a "Aprendido de correcciones".
