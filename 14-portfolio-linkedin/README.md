## Cómo usarlo
**README de perfil:** crea en GitHub un repositorio **público** llamado `davidcormar` → añade un `README.md` con el contenido de `github-profile-README.md` (sustituyendo los `[corchetes]`).

**Portfolio en GitHub Pages (gratis):**
1. Crea un repo público llamado `davidcormar.github.io`.
2. Sube `portfolio/index.html` como `index.html` en la raíz.
3. En 1-2 minutos estará en `https://davidcormar.github.io`.

Para verlo en local: doble clic en `portfolio/index.html`.
