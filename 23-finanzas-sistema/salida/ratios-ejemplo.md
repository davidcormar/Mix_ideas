# Lectura rápida de resultados · Aeroficticia S.A. (empresa INVENTADA para practicar)

> Semáforos **orientativos**: cambian mucho según el sector (una eléctrica y una de software no se comparan). Compara siempre con la propia empresa en años anteriores y con 2-3 competidores. Herramienta educativa, no recomendación de inversión.

| Ratio | Valor | | Qué te dice |
|---|---|---|---|
| Margen bruto | 45,0% | 🟢 | cuánto queda de cada euro vendido tras el coste directo |
| Margen operativo (EBIT) | 17,5% | 🟢 | rentabilidad del negocio antes de intereses e impuestos |
| Margen neto | 12,5% | 🟢 | lo que acaba siendo beneficio |
| ROE | 16,7% | 🟢 | rentabilidad para el accionista (ojo: la deuda la infla) |
| ROIC (aprox.) | 11,7% | 🟠 | rentabilidad del capital invertido; la mejor señal de calidad |
| Deuda neta / EBITDA | 1,5x | 🟢 | años de EBITDA para pagar la deuda |
| Cobertura de intereses | 10,5x | 🟢 | veces que el EBIT paga los intereses |
| Liquidez corriente | 1,4x | 🟢 | activo corriente / pasivo corriente |
| Margen de flujo de caja libre | 14,2% | 🟢 | caja real que genera por euro vendido |
| Conversión a caja (FCF / beneficio) | 1,1x | 🟢 | ¿el beneficio se convierte en caja? |
| PER | 20,0x | 🟠 | años de beneficio que pagas al precio actual |
| EV / EBITDA | 11,5x | 🟢 | valoración de toda la empresa (incluida la deuda) |
| Rentabilidad por FCF | 5,7% | 🟢 | FCF / capitalización: el 'interés' que da el negocio al precio actual |
